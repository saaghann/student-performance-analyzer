
# Student Performance Analyzer

A Python-based student performance analysis application that calculates academic results, evaluates student performance, compares multiple students, and generates visual reports.

## Features

- Single student performance analysis
- Multiple student management
- Automatic grade calculation
- Total marks, percentage, and average calculation
- Highest and lowest subject identification
- Failed subject detection
- Class average calculation
- Class topper identification
- Student ranking
- CSV data storage and retrieval
- Excel report export
- Performance visualization using Matplotlib

## Technologies Used

- Python
- CSV
- Matplotlib
- OpenPyXL

## Installation

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Navigate to the project directory:

cd student-performance-analyzer

Install dependencies:

python -m pip install matplotlib openpyxl

## Run the Application

python main.py

## Application Menu

2. Analyze multiple students
3. View saved student records
